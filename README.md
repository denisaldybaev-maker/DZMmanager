# DZM Manager

Учебный Android-проект для собственного контейнерного формата `.dzm`.

## Что умеет текущая версия

- Android-приложение на Kotlin.
- Выбор одного или нескольких файлов через системный файловый picker.
- Собственный бинарный заголовок `DZM` + версия.
- JSON-манифест внутри контейнера.
- Запись исходных байтов файлов без ZIP/RAR.
- Создание `.dzm` в каталоге приложения.

## Сборка

Нужны Android Studio/Android SDK и JDK 17.

Из корня проекта:

    ./gradlew assembleDebug

Результат:

    app/build/outputs/apk/debug/app-debug.apk

Проект использует Gradle и Android Gradle Plugin. Если установленный Android Studio предлагает обновить плагины/Gradle, лучше сначала открыть проект в Android Studio и дать ему выполнить Sync.

## Важно

Это первая рабочая версия формата. Она пока не реализует извлечение файлов из DZM и полноценную иерархию папок. Это можно добавить следующим этапом.
